# Fotos dos produtos

Joga as fotos das peças aqui. Depois me avisa que eu ligo cada uma ao produto certo no `scripts/main.js`.

## Como me ajudar a organizar

Nomeia o arquivo assim (ou só me diz qual foto é qual peça, que eu renomeio):

```
marca-peca-cor.jpg
```

Exemplos:
```
lacoste-polo-preta.jpg
nike-camiseta-oversized-branca.jpg
adidas-bermuda-sarja-bege.jpg
```

## Formato ideal

- **Proporção:** 3:4 (retrato). O card corta pra esse formato — foto quadrada ou paisagem perde as bordas.
- **Tamanho:** 900×1200 px basta. Acima de 1200 px de largura só pesa.
- **Peso:** até ~300 KB por foto. Se vier direto do celular vai ter 4 MB — me avisa que eu indico como comprimir.
- **Formato:** `.jpg` para foto, `.webp` se quiser mais leve.
- **Fundo:** de preferência o mesmo em todas. Vitrine fica mais uniforme.
